If your Android app includes **Firebase Cloud Messaging** from Google, its data counts as data your app collects. According to the vendor, it collects device or other IDs (collected, not shared: the vendor acts as a service provider).

Matched dependencies: `com.google.firebase:firebase-messaging`.

<Aside type="tip" title="Source">From Google's own Play data disclosure: [firebase.google.com](https://firebase.google.com/docs/android/play-data-disclosure). Checked 2026-10-26.</Aside>

## What to declare

| Data type | Collected | Shared | Ephemeral | Purposes |
|---|---|---|---|---|
| Device or other IDs <br/><small>Via Firebase Installations (installation ID / FCM registration token)</small> | Yes | No | No | App functionality |

Whether each type is **required or optional** for users depends on your app: optional only if users can turn it off and the app honors that.

## Notes

Sends app version and the Firebase user agent, and depends on Firebase Installations (installation ID and token). Purpose is message delivery; if you send marketing or product messages, also declare PSL_DEVELOPER_COMMUNICATIONS. Delivery metrics go to BigQuery only if you enable that export.

## The CSV rows this sets

These are the rows of Google's [Data safety CSV](/reference/csv-format/) that Firebase Cloud Messaging turns to `true` (or `false` for the ephemeral question). Columns: question ID, response ID, value. You also answer the required/optional row for each type.

```csv
PSL_DATA_TYPES_IDENTIFIERS,PSL_DEVICE_ID,true
PSL_DATA_USAGE_RESPONSES:PSL_DEVICE_ID:PSL_DATA_USAGE_COLLECTION_AND_SHARING,PSL_DATA_USAGE_ONLY_COLLECTED,true
PSL_DATA_USAGE_RESPONSES:PSL_DEVICE_ID:PSL_DATA_USAGE_EPHEMERAL,,false
PSL_DATA_USAGE_RESPONSES:PSL_DEVICE_ID:DATA_USAGE_COLLECTION_PURPOSE,PSL_APP_FUNCTIONALITY,true
```

## Detect it automatically

`data-safety-from-code` finds Firebase Cloud Messaging in your `build.gradle` or version catalog, adds these answers with a link to the source, and merges them with every other SDK and with what your own code sends. You get a CSV to import and a report showing where each answer comes from.
