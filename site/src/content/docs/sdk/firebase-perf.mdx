If your Android app includes **Firebase Performance Monitoring** from Google, its data counts as data your app collects. According to the vendor, it collects diagnostics, device or other IDs (collected, not shared: the vendor acts as a service provider).

Matched dependencies: `com.google.firebase:firebase-perf`.

<Aside type="tip" title="Source">From Google's own Play data disclosure: [firebase.google.com](https://firebase.google.com/docs/android/play-data-disclosure). Checked 2026-10-26.</Aside>

## What to declare

| Data type | Collected | Shared | Ephemeral | Purposes |
|---|---|---|---|---|
| Diagnostics | Yes | No | No | Analytics |
| Device or other IDs <br/><small>Via Firebase Installations</small> | Yes | No | No | Analytics |

Whether each type is **required or optional** for users depends on your app: optional only if users can turn it off and the app honors that.

## Notes

Collects app start time, network request latency, CPU and memory usage, and device metadata. Also collects the IP address to map events to countries (decide whether to declare approximate location). Depends on Installations, Remote Config and Sessions. Custom traces, metrics and attributes you define are also sent.

## The CSV rows this sets

These are the rows of Google's [Data safety CSV](/reference/csv-format/) that Firebase Performance Monitoring turns to `true` (or `false` for the ephemeral question). Columns: question ID, response ID, value. You also answer the required/optional row for each type.

```csv
PSL_DATA_TYPES_APP_PERFORMANCE,PSL_PERFORMANCE_DIAGNOSTICS,true
PSL_DATA_USAGE_RESPONSES:PSL_PERFORMANCE_DIAGNOSTICS:PSL_DATA_USAGE_COLLECTION_AND_SHARING,PSL_DATA_USAGE_ONLY_COLLECTED,true
PSL_DATA_USAGE_RESPONSES:PSL_PERFORMANCE_DIAGNOSTICS:PSL_DATA_USAGE_EPHEMERAL,,false
PSL_DATA_USAGE_RESPONSES:PSL_PERFORMANCE_DIAGNOSTICS:DATA_USAGE_COLLECTION_PURPOSE,PSL_ANALYTICS,true
PSL_DATA_TYPES_IDENTIFIERS,PSL_DEVICE_ID,true
PSL_DATA_USAGE_RESPONSES:PSL_DEVICE_ID:PSL_DATA_USAGE_COLLECTION_AND_SHARING,PSL_DATA_USAGE_ONLY_COLLECTED,true
PSL_DATA_USAGE_RESPONSES:PSL_DEVICE_ID:PSL_DATA_USAGE_EPHEMERAL,,false
PSL_DATA_USAGE_RESPONSES:PSL_DEVICE_ID:DATA_USAGE_COLLECTION_PURPOSE,PSL_ANALYTICS,true
```

## Detect it automatically

`data-safety-from-code` finds Firebase Performance Monitoring in your `build.gradle` or version catalog, adds these answers with a link to the source, and merges them with every other SDK and with what your own code sends. You get a CSV to import and a report showing where each answer comes from.
