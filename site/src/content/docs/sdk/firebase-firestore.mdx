If your Android app includes **Cloud Firestore** from Google, its data counts as data your app collects. What it collects depends on how you use it, so each data type below has a condition.

Matched dependencies: `com.google.firebase:firebase-firestore`.

<Aside type="tip" title="Source">From Google's own Play data disclosure: [firebase.google.com](https://firebase.google.com/docs/android/play-data-disclosure). Checked 2026-10-26.</Aside>

## What it can collect

| Data type | When | Collected | Shared | Purposes |
|---|---|---|---|---|
| User IDs | Only if a user is signed in with Firebase Authentication | Yes | No | App functionality |

The skill lists these under *Needs your review* and checks the code for the condition (for example a `setUserId` call) before you include them.

## Notes

Firestore stores whatever end-user data your app writes; declare those types yourself. The SDK itself sends only the Firebase user agent, plus the Firebase Auth user ID on every request when a user is signed in.

## Detect it automatically

`data-safety-from-code` finds Cloud Firestore in your `build.gradle` or version catalog, adds these answers with a link to the source, and merges them with every other SDK and with what your own code sends. You get a CSV to import and a report showing where each answer comes from.
