## Why the Data safety form goes wrong

Every app on Google Play must declare what user data it collects and shares. Play Console's form has 782 possible answers, and most of what an app collects comes from SDKs you didn't write. An ads SDK can share your users' device IDs. A crash reporter collects diagnostics. A "simple" analytics call sends app interactions. Miss one and the form no longer matches the app, which is what Google's review checks.

## How it works

<img src="/media/how-it-works.png" width="1800" height="664" loading="lazy" decoding="async" alt="Four steps: the agent reads AndroidManifest.xml, build.gradle.kts and Kotlin source; findings cite a file and line for each data type; the answers fill data_safety.csv in Play's own format; you import it in Play Console and review before saving." style="width:100%;height:auto;border-radius:1.5rem" />

1. **Scan.** A Python script reads your manifests, Gradle files, version catalog, source and network security config. No network calls, no dependencies.
2. **Judge.** Your agent checks each finding: is this data sent off the device? To a third party? Why? It asks you only what code can't show, such as your deletion policy or what your backend shares.
3. **Fill.** The answers go into Google's own CSV template. Only the answer column changes, so Play Console accepts the import.
4. **Validate and report.** Every conditional question is checked before you upload. The report shows each answer's evidence and what changed compared to your current form.

## Questions

**Does it submit the form for me?** No. You review the CSV and report, then import it yourself. [More in the FAQ →](/faq/)

**Is the result guaranteed to be accepted?** No. It is a draft with evidence; you are responsible for the declaration. [Why →](/faq/)

**Which agents does it work with?** Claude Code as a plugin, and Codex, Cursor, Copilot and other SKILL.md-aware agents through the skills CLI. [Install →](/getting-started/)

## Install

<Install />

Then, in your Android project:

```text
/data-safety-from-code fill the Data safety form for this app
```

Your agent asks for your current Play Console export (App content → Data safety → Export to CSV), scans the project, asks a few questions, and writes `data-safety/data_safety.csv` and `data-safety/data_safety_report.md`.
